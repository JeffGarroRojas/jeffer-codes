Muestra real de lo que hago

Así de simple es un scraping con Python. Sin promesas vacías: código que funciona.

import requests
import csv

resp = requests.get("https://api.example.com/productos")
productos = resp.json()

with open("productos.csv", "w", newline="") as f:
    writer = csv.DictWriter(f, fieldnames=["nombre", "precio"])
    writer.writeheader()
    writer.writerows(productos)
